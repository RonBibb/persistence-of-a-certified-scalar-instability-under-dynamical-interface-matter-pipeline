# D1/D2A one-hour research window: final report

## 1. Success and movement of the bar

D1 succeeded materially. A 32,768-step, 768-bit validated sensitivity and
interval-Newton confirmation produced strict self-maps for both frozen
shooting boxes. The narrow box gives

- event distance: `[1.99749755859375, 1.99761962890625]`;
- interval-Newton image:
  `[0.09901086573766466, 0.09901086594043548]`;
- image width: `2.0277082421991943e-10`.

An independent symbolic audit reproduced the variational equations, initial
sensitivity, event derivatives, and implicit total derivative exactly, and an
exact-rational audit confirmed the stored self-map relations. The resulting
authority is `RIGOROUS_CURVED_BACKGROUND_SHOOTING_ROOT_EXISTS` for the
declared reduced proper-distance shooting problem.

This moves the mathematical bar from a qualified numerical BVP candidate to
a rigorously enclosed shooting root in the declared reduced ODE/wall model.
It does not move the physical-development bar: independent ODE replay,
complete derived-quantity enclosures, stability, a same-development bridge to
the collapse data, and any event-horizon conclusion remain open.

The original preregistered R1 aggregate was not rewritten. Five of its six
cases were strict self-maps; its 4,096-step narrow box missed because the
interval image was wider than that narrow box. The later high-resolution
confirmation was a separately prospective calculation in which both frozen
boxes passed.

## 2. Issues encountered

The first D1 invocation stopped before integration because a correct quotient
derivative enclosure was compared to an exact rational by object equality
rather than containment. That false failure was preserved and the corrected
wrapper changed only that self-test.

D2A did not produce a scientific result. Its frozen cover producer omitted
the general residual fallback declared by the contract. Below the analytic
no-turn threshold, a box was accepted only through the no-turn path
hypotheses. When those hypotheses were unavailable, the code ignored the
already enclosed upper-scalar residual and subdivided toward depth 24. This
created an unnecessary exponential refinement path. The process remained
numerically healthy for approximately 2.07 hours but was ordinary-stopped;
no `RESULT.json` was published. D2A is classified as technical
incompleteness, with no existence or nonexistence inference.

No D2B calculation was attempted. No predecessor, manuscript, archive,
submission, or external record was changed.

## 4. Viability assessment

The line is more viable mathematically than it was at the start of the
window: the central positive-curvature reduced shooting root now has rigorous
interval authority and an independent formula/certificate audit. The main
remaining uncertainty is physical, not whether the reduced root is merely a
floating-point artifact.

The decisive gap is still the separation/development bridge. Tonight did not
answer D2A because of an implementation omission, and it did not authorize
D2B. The research line therefore remains viable but conditional: it has a
substantially stronger static mathematical target, while the connection of
that target to the collapse lineage and any event horizon remains unproved.
