# O1/O2 portability map for a repaired companion

This map distinguishes reusable mechanics from P407-specific scientific
bindings.  Copying either runner intact would silently point a new experiment
back to the lineage that O4 left physically unqualified for causal inference.

## O1 terminal-interface producer

Source inspected:
`../lin-causal-extension-window-20261001T093437Z/p407_r3_seed_interface.py`.

### Reusable mechanics

- canonical JSON serialization and SHA-256 array records;
- atomic immutable JSON/NPZ publication;
- per-resolution recoverable units;
- exact checkpoint revalidation before resume;
- independent primary/alternate parent seeding;
- full terminal leaf-certificate collection; and
- refusal to overwrite a terminal interface.

### Must be replaced or parameterized

- the P401/P407 module paths and `PARENT_SEEDS`;
- hard-coded `RESOLUTIONS=(157,165,173)` and terminal H-steps;
- the assumption of exactly 80 P407 knots;
- the expected historical terminal profile hashes;
- the P407 secant schedule and represented-spacetime loader; and
- the binary64 precision declaration if the repaired companion differs.

For the repaired companion, exact profile-hash equality is a replay gate only
after an independent first production has been sealed.  It cannot be invented
as a pre-production scientific target.

## O2 null-localization runner

Source inspected:
`../lin-causal-extension-window-20261001T093437Z/o2_null_localization.py`.

### Reusable mechanics

- atomic per-trace units and immutable final publication;
- terminal-profile lookup from an authenticated interface;
- coordinate/Hamiltonian dual formulations;
- strict-tolerance, angular-label and surface-resolution controls;
- symmetric curve comparison and projection/coverage gates;
- caustic, crossover, ordering, domain and normalized-null-defect checks; and
- separation of primary-family diameter from the numerical control envelope.

### Must be replaced or generalized

- `build_authenticated_spacetime`, which is explicitly P407-specific;
- P408-R2 `science.py` semantics unless independently shown identical for the
  repaired companion;
- fixed terminal labels, common observation H-steps and N=165 primary choice;
- the inherited `0.05` native-cell target and 16-of-17 count;
- the control envelope, which currently lacks evolution-resolution and
  outer-domain transfers; and
- the claim firewall, which must bind the new companion's physical admission
  rather than merely rename P407 fields.

The portable adapter should expose a small authenticated interface:

```text
development_id
physical_model_id
time_orientation_id
boundary_model_id
domain_id
evolution_resolution_id
state_times
metric_and_first_derivative_query(t,r,z)

```

The comparator must report distances in model-length units first and native
cells second.  Evolution and domain controls enter `E_num`; they are not
descriptive side tables.

## Fate interface

Reuse the strict role-independent event identity and external reviewed-resolver
boundary in `../launch-fate-interface-2026-09-12/launch_fate.py`.  Do not copy
the dormant P408-R2 optional native path: it calls undefined
`_validate_native_artifacts`.  A repaired adapter must recognize fixed
producer/contract identities independently of candidate-controlled JSON.

## Required new components

1. a repaired-companion spacetime adapter implementing the interface above;
2. an evolution-resolution/domain factorial for `E_num`;
3. full-surface `b` and `lambda` retention for the terminal-tail diagnostic;
4. a reviewed native exterior/capture resolver for the fate interface; and
5. a Lane-C comparator between the null-front uncertainty tube and nested
   certified launch brackets.

These components can be built without rerunning P407 and without changing any
predecessor.  They should be trialled first on the stationary black-string
control and analytic Schwarzschild fate fixtures, then bound to the repaired
companion.
