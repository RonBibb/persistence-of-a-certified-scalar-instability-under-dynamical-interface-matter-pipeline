The attempted fixed-separation cover is technically incomplete and supports no
physical conclusion. The frozen producer did not implement the full fallback
declared by its contract: below the analytic no-turn threshold it subdivided
whenever the no-turn path hypotheses were unavailable, even though it had
already enclosed the upper-scalar residual. It never used that residual as a
direct exclusion certificate on that side of the threshold.

The run remained numerically healthy for about 2.07 hours, but continuing it
would have spent exponentially increasing work on a source-level omission and
could only have produced an inefficient incomplete cover. It was therefore
ordinary-stopped without a `RESULT.json`. This is not evidence for or against a
fixed-separation positive-curvature solution.

The successor should implement the contract's general rule on every box: a box
is excluded when either upper-wall residual rigorously excludes zero; the
analytic no-turn argument is an additional cheaper certificate where its path
hypotheses hold. Because the authorized start window had closed, no corrected
scientific run was launched.
