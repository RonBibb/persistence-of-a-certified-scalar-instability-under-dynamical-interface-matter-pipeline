# Inspection ledger and verification depth

## Purpose

This ledger distinguishes direct scientific inspection, machine parsing and
rederivation, content-identity checks, and material deliberately not used. A
hash match establishes identity; it is not presented as independent scientific
verification.

machine-readable results and rederives or checks:

- D1 terminal/result/audit linkage, both step levels, strict self-maps, root and
  geometry gates;

- the four classification counts and zero unresolved boxes;
- the conservative `0.0077` floor and the exact worst-box lower bound;
- exact D1-minus-D0 and D1-over-D0 interval arithmetic; and
- agreement between the sealed payloads and the exact theorem table.

`reduction_identity_check.py` independently checks five exact algebraic
identities. The older consolidated verifier is also replayed. These checks pass
on macOS and Linux.

## Identity-checked but not promoted to independent review

Twenty-one parent files named in `AUTHORITY_BINDINGS.json` were rehashed. This
includes causal-line context records that are retained only to enforce the
lineage boundary. Hash verification confirms that the packet points to the
intended sealed bytes; it does not adopt every interpretation in those files.

The D2A post-run audit reports that all 86 immutable checkpoint content
addresses were verified. This window replays that audit and checks the terminal
cover directly, but does not manually reread every optional checkpoint payload
as a separate scientific analysis.

- unsealed output from the concurrent initial-data line;
- any new extension of the failed/incompatible P407/O4 late evolution;
- unpublished external correspondence or submission records;
- parameter values outside the exact frozen literals;
- launch values outside exact `0<=a<=v0`; and
- any dynamical, MOTS, null-ray, or event-horizon output as support for the
  static theorem.

## Claims that remain unverified

- persistence of the static mismatch over a parameter neighborhood;
- global uniqueness outside the certified D1 root interval;
- spectral or nonlinear stability of the D1 branch;
- a same-action Cauchy embedding or dynamical selection mechanism;
- a physical exterior and causal horizon for a compatible evolution; and
- absolute literature priority for the paired theorem.
