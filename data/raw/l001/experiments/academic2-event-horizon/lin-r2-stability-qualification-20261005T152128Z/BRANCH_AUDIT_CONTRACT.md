# D1 static-root to scalar/radion stability branch audit

## Question

Does the previously completed gauge-invariant scalar/radion calculation act on
the same central static solution now certified by the D1 uniqueness theorem,
or is it an unrelated numerical background?  If it is the same branch, what is
the strongest defensible stability statement?

## Frozen evidence

This read-only audit binds the D1 high-resolution interval-Newton result, the
independent D1 geometric enclosures, the D1 model source, the qualified
fine-collocation background receipt, and the complete sealed stability package.
It does not use the short generalized-harmonic response as a premise.

## Admission checks

1. Verify every file in the sealed stability manifest.
2. Verify exact agreement of all six action/wall parameter values across D1,
   the stability contract, and the collocation receipt.
3. Require the collocation lower-wall scalar value to lie inside the D1
   interval-Newton root enclosure, its proper separation to lie inside the D1
   event bracket, and its curvature to lie inside an independent D1 curvature
   enclosure.
4. Reconstruct the stability decision: negative physical `mu`, positive
   kinetic norm, nonzero invariant proper-separation overlap, passed analytic
   and symbolic controls, passed independently differentiated mode residuals,
   and a mass magnitude exceeding 100 times every declared numerical
   sensitivity.
5. Verify the gauge-invariant/regular derivation record is the file bound by
   the pre-outcome stability contract and manifest.

## Decision boundary

Passing establishes that the existing resolved instability is finite-resolution
evidence on the same authenticated central static branch.  It does not convert
the spectral calculation into an interval theorem for the exact background:
no rigorous perturbation-operator enclosure or eigenvalue-continuity bound from
background error to `mu` has been supplied.  It also does not extend the
instability across a finite parameter neighborhood, determine a globally
lowest mode, or predict the nonlinear endpoint.
