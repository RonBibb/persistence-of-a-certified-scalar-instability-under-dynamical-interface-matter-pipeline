# Exact reconstruction of the saved global exclusion cover

This test independently implements the arithmetic predicates behind the saved 726-box global first-event cover using Python Fraction. It reads byte-identical copies of the global result and the primary and independent root results. It does not import producer code or invoke Arb. All criteria below are frozen before execution and require reviewer approval.

The baseline must reconstruct an ordered, positive-width, exactly adjacent cover from zero through the exact binary64 value of 0.1, with 19 negative-curvature boxes, 706 scalar-exclusion boxes and one root box, and no unresolved records. For each negative-curvature box, both exact curvature upper endpoints must be negative. For each scalar box, both exact scalar intervals must exclude zero with the same sign, both G_s upper endpoints must be negative, and both G intervals must contain zero. Recorded bracket endpoints must equal the stored cell indices multiplied by 2/8192, and the negative-after index must immediately follow the bracket. Scalar-record launch endpoints must equal their containing box endpoints. Root-box endpoints must match the frozen binary64 labels and the source root intervals. Primary and both independent saved Newton images must lie strictly inside that box; independent exact q_a must exclude zero. No saved pass flag can replace these arithmetic tests.

First-event qualification is inherited from the interval producers: the aggregate records do not retain every pre-event G sign enclosure or every internal cell of the zero cluster. Event bracket arithmetic checks cannot reconstruct that missing flow history. Primary derivative signs available only as displayed bounds are not promoted to exact certificates. The result is saved-cover arithmetic reconstruction, not new validated integration or a new existence theorem.

Seven prospective semantic negative controls must each reject for the named reason: a gap, duplicate root, curvature interval touching zero, scalar residual containing zero, nonnegative transversality, invalid event bracket, and a Newton image touching the root-box boundary. Each control mutates a deep in-memory copy only, then calls the same semantic evaluator without the source hash check. Thus rejection cannot be attributed merely to changed bytes. The original baseline sources and copied input files remain unchanged. A failed baseline is retained and is not rescued by changing tolerances or criteria.

Run once after approval using isolated Python with bytecode disabled from /private/tmp. Preserve raw output, return code, source/code/design hashes, UTC times and runtime. Expected duration is seconds. The independent reviewer must inspect the baseline, targeted control failures and source immutability before classification. A separate isolation determinant test is a possible next step, requiring its own gate.
