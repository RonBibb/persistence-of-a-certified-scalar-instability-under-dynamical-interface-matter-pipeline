computes the same five residuals from those jets, the event length D, curvature

For any representation G and its unchanged primitive rectangle X, let m be
the exact binary midpoint. The segment m+t(x-m), 0<=t<=1, lies in X. Analytic
automatic derivatives evaluated outwardly on X give J(X), hence
   G(x) belongs to G(m)+sum_j J_j(X)*(X_j-m_j).
The same formula is applied directly to -C*G with the frozen C. This is a
rigorous range enclosure, not a changed physical source or new root-center
calculation. The point evaluation G(m) by itself has no physical authority.

Intersect each equivalent enclosure with the old recorded enclosure I.
The ratio 1-width(intersection)/width(I) is a rigorous removable-width
fraction for this enclosing description: the same exact residual is still
contained. It is not a fraction of actual physical error. If the intersection
is empty or the baseline reconstruction disagrees, fail closed.

At a fixed mean-value level the triangle bound is additive: midpoint
evaluation halfwidth plus sum_j mag(J_j(X))*halfwidth(X_j), with outward
rounding excess recorded. These contributions can overlap in the physical
source parameters; their sum bounds a rectangle, not statistically independent
errors. Do not add budgets from different representation levels.

For the fixed-preconditioner ledger, a row's ideal linear interval radius is
