## 2. Arithmetic and runtime trust boundary

### Arb stage and diagnosed implementation failure

Recovery T4 uses Python 3.12.3 executable hash `c86f21d0da9290ece2d7d49a3f7ed52aed59cb029abdf0ea25c79634f6cbe960`, python-flint 0.9.0, and `flint/types/arb.abi3.so` hash `6abaed2e09f6b60e4b26d9c6eb71345ae5e69fc9162fc42e5ff232ef8be75145` (`producer.py:173–181`). This binds specific Python and extension files, not the complete dynamic dependency graph, CPU architecture or every standard-library module. A current runtime inventory cannot retroactively prove historical unrecorded shared-library identities.

The T2/T3 recovery isolates the observed nonfinite original power evaluation on a zero-crossing interval and qualifies explicit integer multiplication. It supports an operation-level implementation issue in the recorded environment, not a blanket Arb/library/platform defect. T4 preserves the physical model and widths; T6 changes propagation route; T7 independently replaces arithmetic. Their successful outputs do not retroactively turn either failed predecessor into a pass.

T4 `producer.py:34–41` constructs exact rational inputs and extracts exact rational lower/upper Arb bounds. These are outward-bound representations, not rationalizations of rounded decimal displays. `:145–163` distinguishes determinant containment and threshold widths from a full exact equality proof.

### Integer interval and exact Fraction stages

Eigenvalue T1R2 `interval.py:1–39` is a 256-fractional-bit fixed-point integer interval implementation: exact Fraction input conversion, floor/ceiling endpoints, four-corner multiplication, reciprocal with zero-divisor rejection, and rational output. This is not IEEE binary64 numerical evolution and does not depend on a hardware floating-point rounding mode for its scientific arithmetic. It still depends on correct Python integer/Fraction semantics, transcription and enclosure method. `Fraction(float)` would only encode a float exactly, not certify its intended real input; the inspected model/config paths use integers and rational strings. This inspection does not establish a blanket no-float theorem for every later imported source.

Width T2 `taylor.py:31–48` computes jet coefficients, establishes strict whole-step Picard containment, and adds the order-th coefficient evaluated over the whole tube as a Taylor remainder. The finite qualification controls support this implementation; they are not, alone, a universal proof of all integration steps. Saved exact endpoint fractions can be independently checked for all endpoint predicates; absent interior tubes cannot be reconstructed from endpoint fractions alone without fresh computation.

Width T7 `producer.py:7–54,58–74` provides an exact finite polynomial recurrence and saved cancellation coefficients. This is an appropriate small complete-checker target for the **local coefficient statement**, unlike a sampled sixth-order residual. A checker must independently reconstruct the recurrence, truncation order, boundary equations and coefficient conversion, not merely verify that saved coefficients equal the advertised values. A finite local series cannot certify a finite-width remainder.
