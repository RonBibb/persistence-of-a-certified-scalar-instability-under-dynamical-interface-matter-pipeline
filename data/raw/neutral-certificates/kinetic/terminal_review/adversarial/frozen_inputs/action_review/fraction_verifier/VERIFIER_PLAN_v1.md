# Prospective independent exact-Fraction saved-certificate verification

This checker is a separate numerical acceptance gate. Its source v1 and this plan are frozen before any import/execution of checker functions or interval/control evaluations. Only metadata hashing and ast.parse have been used. Root and existing reviewers must statically admit the exact candidate; then root creates FRACTION_VERIFIER_ADMISSION.json naming this candidate, its digest and admitted=true. No acceptance follows from source freeze itself.

The sole worker is verify_saved_certificate.py, with a mandatory default supervisor mode that spawns the same file once with -B and private --worker. The supervisor OS timeout is original 16:03:42Z minus two seconds; worker SIGALRM uses the same original deadline without extension. No producer module is imported, and no NumPy, Flint, floating scientific arithmetic, root solve, adaptive flow or new response/background case is run. stdlib Fraction represents exact interval endpoints, with exact rational addition/multiplication/division/squares. Float use is confined to wall-clock timeout plumbing.

Required launch arguments are --certificate <packet>/certificate --expected-pointer-sha256 <frozen final LATEST hash> --output <fresh directory>. Exact pointer freeze must occur after producer cells stop changing. guard verifies this checker's own admitted candidate/files, every inherited original/snapshot pair, producer saved guard/fingerprint/source bindings, exact immutable payload digest and controls digest. An existing nonempty output is refused, and failure receipts use distinct names rather than overwriting prior failure evidence. No checker run may silently repair a producer or auditor failure.

The exact root-box launch is recomputed in Fraction interval arithmetic from frozen rational A/model inputs, yielding an exact rational k image (usually narrower than rounded producer k). The checker reads saved integer pairs only as rationals over 2^192. It verifies the fixed step/order/precision/chunk protocol, original D box and exact required cell count. It follows every saved chunk in order with exact s/index/final-short-cell checks and verifies chunk hashes.

For each saved cell, previous certified endpoint Y and saved box B give the exact rational image Y+[0,h]F(B); it must lie STRICTLY inside B. Independently reconstructed normalized degree-four Taylor coefficients at Y and fifth coefficient over B then enclose every state on [0,h] and at h. Exact rational Horner evaluation is used, so no extra dependency enlargement from an expanded polynomial form is introduced. Saved whole-cell/endpoint bounds must contain those rational enclosures; the checker never rounds its own endpoints onto the producer grid. These checks validate inclusion inductively rather than selecting new Picard boxes or integrating an independent adaptive trajectory.

The same exact subcell Taylor bound checks every D-event overlap, retaining all six states and q_s=E. The final payload must contain the reconstructed full collar/event hull, match the certified last endpoint/s/count and inclusion-iteration maximum, and agree with RESULT inventory/booleans. Strict positive-k/E and upper-k/E/mPhi²/negative-H/positive-event-width gates are recomputed from certified saved enclosures. Both upper residual intervals must enclose zero and contain the independently calculated exact rational expressions; this remains a root-subset consistency check, not new root existence. Derived coefficient bounds and the exact rational Delta comparison are checked. The exact first integral and E=exp(-W) are analytic flow identities, with the former checked as interval consistency per saved whole tube.

The producer's coefficient DIGEST is intentionally not compared with exact Fraction coefficients: producer coefficients include directed rounding and generally differ while still enclosing the independent rational coefficients. The rigorous numerical acceptance obligation is containment of independent Picard/Taylor images, endpoints and events, together with initial/parameter coverage and gates. No agreement threshold or decimal tolerance appears anywhere.

Every successful chunk writes progress with exact count and digest provenance. On failure, stage/index/s and traceback are retained. A rerun requires a fresh output and fresh explicit authorization/admission if code changes; v1 and its failure must remain immutable. A frozen-code run timing out leaves this verification gate HELD. The operation has only 16365 fixed-degree saved cells; rational denominators are finite and reconstructed afresh from 192-bit saved endpoints per cell, so they do not accumulate through an unrounded long IVP. No empirical performance claim is made before execution; deadline guards retain the original maximum regardless of speed.

A complete PASS requires all cells, all gates and exact final-source/pointer stability. A validated prefix or inconclusive gate is explicitly not a full certificate. The checker result is numerical enclosure acceptance only; the independently reviewed weighted all-mode theorem, actual mean/source/action norm and any conditional charged continuation remain separate scientific review obligations. No smooth-trajectory/no-ghost/IR/old-cap/nonlinear upgrade or successor is authorized.
